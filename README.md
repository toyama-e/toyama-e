## Projects

### 🏗️ 株式会社外山建設 コーポレートサイト

> 新潟県三条市で2名が営む建設会社の公式サイト。現場スタッフ1名の採用を主目的に、工事相談の受付と会社の人柄を伝えるサイトとして制作しました。

- **Stack:** Next.js · TypeScript · Tailwind CSS · Cloudflare Pages · Vitest · Google Analytics 4
- **担当:** 要件整理 · 情報設計 · UIデザイン · 実装 · テスト · デプロイ
- **こだわり:** 本業を妨げない運用設計 · 導入・運用コストの抑制 · LINE通話を活用した問い合わせ導線
- **UX設計:** 20〜40代の求職者を意識したシンプルなデザイン · 人柄が伝わる写真と情報構成 · スマートフォンを最優先したレスポンシブ対応
- **表示確認:** 320px · 375px · 390px · 430px · 768px · 1024px · 1440px
- 🔗 [Webサイト](https://toyama-kensetsu.com) (2026年8月)
- 🔗 [GitHub](https://github.com/toyama-e/Toyama-Construction)

### 💻 三条ものづくりノート
> 新潟県三条市の小学生向け、ものづくり体験デジタルポートフォリオアプリ  
> 「Before → Process → After」で体験した画像と動画をアップロードし、FFmpegでショート動画を自動生成。

- **Stack:** Next.js · FastAPI · TypeScript · Docker · Vertex AI (Gemini 2.5 Flash) · GCS · FFmpeg
- **成果:** 「AIを活用したアイデア発表会」（新潟県三条市）にて発表（2026年4月）
- **こだわり:** 小学5年生が迷わず使えるクリック最小化UI · AI感想フィードバック（Gemini 2.5 Flash） · ショート動画自動編集（担当）
- 🔗 [GitHub](https://github.com/toyama-e/sanjo_makers_note.git)
